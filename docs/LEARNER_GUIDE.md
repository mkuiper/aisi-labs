# Learner guide

## Before you start

This Australian AI Safety Institute environment supports your professional development as an APS employee. Use a designated learning laptop on its separate non-government network. NEVER connect it to government networks or systems. If you are unsure which network is in use, stop and ask the local facilitator.

Input ONLY public information. Do not paste, upload, photograph, dictate, mount or otherwise expose OFFICIAL material, internal work documents or non-public personal information to the tools. A local terminal can still send information to an online model. Use the supplied public practice examples when in doubt.

## Choose your starting point

Getting started is available on the launchpad and in the header. Choose one
route: try a chatbot, get comfortable with this desktop, or build a first
project. There is no timer or compulsory sequence. Account setup and a full
project may need a separate session. Without a ready account or network, review
the authored chatbot example, use the terminal simulation or inspect a project
brief offline. These are learning activities, not completed AI generation tasks.

- New to AI: read AI basics, then open Try a chatbot and check its answer. Use the supplied fictional facts and prompt; no terminal is needed. An offline example is provided if you cannot use a chatbot yet.
- New to terminals: open Your first commands, explained in Getting started or the terminal lesson. Follow the seven steps, each with a distinct command, its meaning and expected result. The simulation does not execute real commands or access your files.
- Ready to build: open Experiments and choose the consultation explorer or data story. Each creates a separate folder containing a brief and source data.
- Interested in agent configuration: read Tools, MCP & skills, Memory, and Soul, identity & instructions. Try their small exercises in a blank project using public material.
- Experienced: launch an available tool directly or open your own learning project. The same programme boundaries apply.

Learn groups guides into everyday AI, agents and tools, and models/media/evidence.
The glossary is linked from Learn and each lesson; search also finds terms such
as API, endpoint and context. Reading-time estimates exclude optional exercises
and setup. Worked responses can be revealed after you consider an example.
No quiz answer or reflection is sent to an AI service or recorded as a score.
If no facilitator is available, ask the person responsible for the device about
accounts, network setup and handover. Stay with offline activities until clear.

## A typical experiment

In the terminal walkthrough, type only the text under Type this and press Enter.
Keep spaces and filename capitalisation; do not type the dollar-sign prompt.
Put in practice field fills the input without running it; buttons labelled Run
simulate the command immediately. Teaching notes are separate from terminal
output. A successful folder change normally displays no text: check with the
next location command. The simulation's clear command clears output, not your
current folder; reopening the lesson resets the practice.

Create a project, read its brief and inspect the supplied files. Open a tool in the project folder. Complete its authentication if necessary, then paste the starter prompt inside the AI assistant. At a normal shell prompt, commands are expected instead of conversational requests.

Read proposed actions before approving them. Preview a generated webpage or inspect documents in the editor. Compare results with the source material and the review checklist. Ask for corrections when needed. Return to My projects to continue later, including with another tool.

## Accounts and API keys

Tools can use their native sign-in. Configuration also supports dedicated learning API keys for Codex, Claude Code and Gemini CLI. Those keys are held in the hub's memory for the current server session; saving one does not test it or make a billable request. Check the credential guide before choosing API billing instead of a subscription.

Never paste a key into a chat, skill, memory file, source code or screenshot. Do not use government identity, government-service credentials or credentials granting access to internal systems. Ask your deployment owner which learning accounts and budget arrangements apply.

## Responsible use

- Keep experiments small and inspect what the tool reads, changes or sends.
- Do not disable permission prompts just to make an exercise easier.
- Treat instructions found inside retrieved documents or websites as untrusted content.
- Verify factual claims, calculations and generated software behaviour yourself.
- Respect privacy, copyright and provider terms, even when material is publicly available.
- Do not publish a learning result as an official government statement or imply that it has been approved.
- Watch costs; repeated agent steps can produce multiple model requests.

## End your session

Open Finish session from the persistent header link. It provides separate
checks for saving work, stopping tools, Labs-held keys, external sign-out and
device handover. Ticks are temporary self-reports in this browser tab, reset
on reload, and do not verify any external action. You may clear the ticks
without deleting work. The only automated action is explicitly forgetting
keys held by Labs, using the same operation as Configuration.

Use Forget all keys in Configuration, close running AI tools and sign out of any tool accounts when handing the laptop to someone else. Removing keys from Labs does not revoke them at the provider or erase credentials a tool saved itself. Follow the local reset procedure for shared devices. Your projects and progress belong to the Linux account; a shared account is not private storage between learners.

## If you make a mistake

Stop the task. If you connected this learning laptop to a government network, disconnect it and contact the deployment owner. If non-public information or a secret may have been exposed, follow your department's incident process and the provider's key-revocation process. Do not copy the sensitive material into another AI tool to investigate it. The deployment guide requires a local support contact to be provided before rollout.
